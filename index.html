Gobernanza

Human-in-the-Loop

La IA acelera; el ingeniero humano define, valida, audita y aprueba. Mitigamos automation bias, alucinaciones, código caja negra, vulnerabilidades ocultas y amplificación de deuda técnica.

Catálogo de riesgos y modelo HITL

Qué es este framework

No es una colección de prompts

Es un sistema integrado de gobernanza técnica: cada módulo produce entregables (EVID-P0N) que alimentan la evaluación ISO, la auditoría OWASP y la defensa académica o profesional del artefacto de software.

Flujo

  • P01 → Spec + threat model
  • P02 → Review + tests
  • P03 → Informe OWASP
  • P04 → ADR + supervisión
  • P05 → Declaración ética
  • P06 → Autoevaluación cognitiva

Prompt engineering

  • Chain-of-Thought estructurado
  • Self-consistency en validación
  • Adversarial en seguridad
  • Reflection y meta-prompting
  • Tree-of-thoughts en diseño

Estándares

  • ISO/IEC 25010:2023
  • OWASP Top 10 2021
  • SOLID · Clean Code
  • NIST AI RMF · UE AI Act
  • Normativa colombiana

Audiencia

Diseñado para contextos exigentes

  • Estudiantes Ingeniería TIC

    Metodología defendible ante jurados, con evidencia y declaración de uso de IA.

  • Desarrolladores

    Validación técnica, deuda técnica, complejidad y seguridad antes de merge.

  • Auditoría y calidad

    Métricas ISO, controles OWASP y trazabilidad requisito→código→prueba.

  • Gobernanza IA

    Supervisión humana, transparencia y alineación NIST / Reglamento UE.
